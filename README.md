# Локальная идентификация СДУ для раннего предупреждения критических переходов

Исследовательский проект посвящен восстановлению локальной стохастической
динамики по коротким, зашумленным и неполным временным рядам. Основной вопрос:
можно ли отличить потерю устойчивости от роста процессного шума, если оба
механизма увеличивают наблюдаемую дисперсию.

Репозиторий содержит исполненный Jupyter Notebook, переиспользуемый Python-код,
синтетические и эпидемиологические данные, результаты сравнительных
экспериментов и исходник научного отчета.

## Методы

В едином экспериментальном протоколе сравниваются:

- классические сигналы раннего предупреждения: дисперсия, AR(1), скорость
  восстановления, коэффициент вариации и асимметрия;
- Moment OU и Kalman OU;
- SINDy-STLSQ и Bayesian SINDy с априорным распределением spike-and-slab;
- Neural SDE с наблюдаемым состоянием и Neural SDE со скрытым состоянием;
- Decision Tree, Random Forest, Easy Ensemble, RUSBoost, Balanced Bagging и
  EWSNet для классификации начала эпидемической волны;
- Persistence, Local Kalman-OU, LSTM и GRU для прогнозирования
  COVID-индикаторов.

Синтетическая часть включает OU-процесс и три нелинейные нормальные формы:
седло-узел, транскритическую и бистабильную системы. Для нелинейных систем
используется диффузия, зависящая от состояния. Модели получают одинаковые
окна, горизонты и разбиения. Помимо ROC-AUC оцениваются RMSE параметров, доля
успешных оценок, покрытие интервалов, ложные тревоги и время упреждения.

## Быстрый старт

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e .
```

Открыть исполненный ноутбук:

```bash
make notebook
```

Повторно выполнить все ячейки на сохраненных результатах тяжелых моделей:

```bash
make execute
```

Полностью пересчитать синтетические сравнительные эксперименты:

```bash
make benchmarks
```

Собрать таблицы, рисунки и PDF-отчет:

```bash
make report
```

Для сборки отчета требуется XeLaTeX. Если в системе установлен Times New
Roman, он используется как основной шрифт. В противном случае LaTeX выбирает
Liberation Serif или TeX Gyre Termes. Готовый PDF уже включен в репозиторий и
содержит внедренные шрифты.

## Уровни воспроизводимости

Предусмотрены два режима выполнения:

1. `make execute` повторяет анализ в ноутбуке на включенных построчных
   результатах и предсказаниях. Этот режим подходит для обычного компьютера.
2. `make benchmarks` заново обучает стохастические и нейросетевые модели и
   требует существенно больше времени.

Начальные состояния генераторов, номера обучающих и тестовых траекторий, длины
окон, горизонты и правила калибровки порогов зафиксированы в коде. Таблицы и
рисунки отчета строятся командой `make report` непосредственно из файлов в
`data/`.

## Данные

### COVID-19 в Санкт-Петербурге

- источник: [COVID-19.SPb.monitoring](https://github.com/alexei-kouprianov/COVID-19.SPb.monitoring);
- зафиксированная версия: `77e44c9194ba209d69bc6ef082d05be347e04903`;
- включенный файл: `SPb.COVID-19.united.csv`;
- лицензия исходного репозитория: CC BY-SA 4.0.

Доля положительных тестов рассчитывается как
`CONFIRMED.sk / PCR_TESTS`. Значения вне диапазона `[0, 1]` исключаются до
построения признаков.

### Недельный ряд ОРВИ

- источник: [ITMO-NSS-team/Epidemic_AutoML](https://github.com/ITMO-NSS-team/Epidemic_AutoML);
- зафиксированная версия данных: `45b3459bb41df40afc98a02115cc3f2b3dec8ef0`;
- исходный путь: `Data/Данные с 1990 по 201930.xlsx`, лист `Лист1`.

Файл `SPb_ORVI_weekly_labelled.csv` является детерминированной выборкой для
Санкт-Петербурга. Заболеваемость рассчитывается как
`100000 * wd_total / qty_total`, а значение `wda_total == "Э"` используется как
официальная метка эпидемической недели.

### Сохраненные результаты

- `article_neural_predictions.csv`, `covid_rolling_neural_predictions.csv` и
  `covid_strategy_predictions.csv` содержат предсказания LSTM и GRU;
- `covid_rolling_all_predictions.csv` добавляет Persistence и Local Kalman-OU
  на тех же датах;
- `extended_sde_*.csv` и `nonlinear_sde_*.csv` содержат результаты отдельных
  синтетических траекторий, включая неуспешные оценки;
- `orvi_ewsnet_predictions.csv` содержит вывод 25 предварительно обученных
  вариантов EWSNet без дообучения;
- `orvi_classification_results.csv` содержит результаты классификации начала
  эпидемической волны.

Большие исходные таблицы и веса нейронных сетей не распространяются вместе с
репозиторием. Включены только необходимые обработанные данные и
детерминированные предсказания.

## Основные результаты

- Рост дисперсии не идентифицирует механизм изменения: одинаковый эффект дают
  снижение локальной устойчивости и усиление процессного шума.
- Явная модель наблюдений повышает долю успешных оценок при редких наблюдениях,
  шуме измерения и пропусках.
- На нелинейных системах ни одна гибкая модель не получает устойчивого
  преимущества во всех режимах.
- Bayesian SINDy переносит неопределенность выбора структуры в интервалы, но
  номинальный уровень покрытия требует эмпирической проверки.
- В задаче раннего предупреждения ОРВИ лучший PR-AUC показал Easy Ensemble:
  0,713 и 0,747 на горизонтах 4 и 5 недель.
- В прогнозировании COVID-индикаторов победитель зависит от целевого показателя
  и горизонта; единой доминирующей рекуррентной архитектуры нет.

## Ограничения

Работа не является готовой системой эпидемиологического оповещения. Синтетические
системы одномерны, процессный шум белый, а пропуски считаются полностью
случайными. Bayesian SINDy ограничен кубической библиотекой и выбранным
априорным распределением. Neural SDE со скрытым состоянием использует
факторизованное вариационное распределение и переходную плотность Эйлера.
Эпидемиологические результаты получены ретроспективно и требуют независимой
проспективной проверки.
